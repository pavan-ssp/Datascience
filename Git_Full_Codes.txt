Add & Commit :
-------------

add- adds new or changed file in your working directory to the Git staging area. 
 
git add <-file name-> --- inorder to add individual file

git add .   --- inorder to add multiple files which are newely added or modified or deleted 

commit- it is the record of change  -------    git commit -m “some message”

 Pull Command :
 ----------------
 
 git pull origin main
 
 used to fetch and download content from a remote repo and
 immediately update the local repo to match the content
 
 
 Undoing Changes :
 -----------------
 
 Case 1 : staged changes
               git reset <-file name->
               git reset
 Case 2: committed changes (for one commit)
              git reset HEAD-1
 Case 3: committed changes (for many commits)
              git reset <-commit hash->
              git reset --hard <-commit hash->
